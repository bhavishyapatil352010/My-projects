Smart Data Analyzer 🔍

Version 1.0 — Prototype

Smart Data Analyzer is a beginner-friendly Python project that takes numerical input from the user and performs basic data analysis using Object-Oriented Programming (OOP).

This project is currently a prototype. It represents the starting point of a bigger idea, and I plan to make it better, more capable, and more organized as I continue learning and developing my Python skills.

🚀 Features

- Accepts comma-separated numbers from the user.
- Converts the input into integers.
- Handles empty and invalid input.
- Counts the total number of values.
- Calculates the sum and average.
- Finds the largest and smallest numbers.
- Displays the average up to two decimal places.
- Uses a class-based structure with Python OOP.

🛠️ Built With

- Language: Python
- Concepts: Classes, Objects, Methods, Exception Handling, Lists, and Basic Data Analysis
- External Libraries: None

▶️ How to Run

1. Make sure Python is installed on your device.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Run the following command:

python smart_data_analyzer.py

5. Enter numbers separated by commas when prompted.

Input:
